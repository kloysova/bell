# チャイム

学習カレンダーに書いた予定どおりに、学校のチャイム（ウェストミンスターの鐘＝
キーンコーンカーンコーン）を鳴らすだけの macOS アプリ。

その日が「平日」なのか「夏休み A」なのか「定期考査日」なのかを日付から判定して、
その日課の区切り時刻にチャイムを鳴らす。Dock に入る普通のアプリで、ウインドウで
今日の予定を見ながら使える。

macOS の標準機能だけで動く（追加インストールは不要）。Python 3 は macOS に最初から
入っているものでよい。

---

## 用意するもの

このリポジトリには**予定データと音源は入っていない**（下の「ライセンス」参照）。
動かすには `data/` を自分で用意する。音は初回に自動で合成される。

```bash
git clone https://github.com/kloysova/bell.git
cd bell
# data/calendar.json と data/routines.json を作る（下記）
python3 chime.py today
```

`data/` が無いまま実行すると、その旨と作り方を案内して終了する。

---

## data/ を用意する

2つのファイルを自分で書く。`data/config.json` は初回実行時に自動で作られる。

### data/calendar.json — 日付ごとの区分

各日に文字列のラベルを付ける。ラベルは月間カレンダーのマス目に書く言葉のつもりで、
`""`（空＝通常の学校日）でよい。

```json
{
 "study_period": { "start": "2026-07-01", "end": "2027-04-06" },
 "days": {
  "2026-07-01": "",
  "2026-07-03": "1学期期末考査",
  "2026-07-11": "夏休み B",
  "2026-07-13": "夏休み A",
  "2026-07-20": "海の日",
  "2026-09-01": "2学期開始"
 }
}
```

- `study_period` の外の日は何も鳴らない
- `days` に無い日も鳴らない（休みにしたい日は書かなければよい）

### 日課タイプの決まり方

その日のラベルから、次の順で 9 種類のどれかに決まる。

| # | 条件 | 日課タイプ |
|---|---|---|
| 1 | `config.json` の `date_overrides` に指定がある | 指定したもの |
| 2 | `study_period` の外 / `days` に無い | 鳴らさない |
| 3 | `夏休み` `冬休み` `春休み` の次が `A` / `B` / `休` | `長期休暇A` / `長期休暇B` / `長期休暇休` |
| 4 | `考査` を含む | `定期考査日` |
| 5 | `休養調整日` | `休養調整日` |
| 6 | その他の記載（`海の日` など祝日名） | `祝日` |
| 7 | 記載なし（`2学期開始` `3学期開始` `修了` を含む） | 曜日で `学校平日`(月-金) / `学校土曜` / `通常日曜` |

長期休暇の A/B/休 は祝日と重なっても優先される（サイクルを崩さないため）。

### data/routines.json — 日課ごとの時刻表

上の 9 種類のうち、使うものを書く。`time` がチャイムを鳴らす時刻（各ブロックの
開始時刻）。

```json
{
 "weekday_tasks": {
  "0": { "朝": "数学 例題", "放課後": "数学 問題集" },
  "2": { "朝": "英文解釈", "放課後": "英作文" }
 },
 "routines": {
  "学校平日": {
   "title": "学校期間 - 平日",
   "events": [
    { "time": "06:30", "label": "起床・朝食", "sound": "chime" },
    { "time": "07:00", "label": "朝自習",     "sound": "chime", "task": "朝" },
    { "time": "08:35", "label": "学校授業",   "sound": "chime" },
    { "time": "15:20", "label": "放課後",     "sound": "chime", "task": "放課後" },
    { "time": "21:30", "label": "消灯",       "sound": "night" }
   ]
  },
  "学校土曜":   { "title": "土曜", "events": [] },
  "通常日曜":   { "title": "日曜", "events": [] },
  "長期休暇A":  { "title": "長期休暇 A", "events": [] },
  "長期休暇B":  { "title": "長期休暇 B", "events": [] },
  "長期休暇休": { "title": "長期休暇 休", "events": [] },
  "定期考査日": { "title": "定期考査日", "events": [] },
  "休養調整日": { "title": "休養調整日", "events": [] },
  "祝日":       { "title": "祝日", "events": [] }
 }
}
```

| キー | 内容 |
|---|---|
| `time` | `HH:MM`。この時刻に鳴る |
| `label` | ウインドウと通知に出る文字列 |
| `sound` | `chime`（通常）/ `night`（消灯用）。省略すると `chime` |
| `task` | `weekday_tasks` から曜日別の課題名を引いてラベルに足す（任意） |

`weekday_tasks` はキーが曜日（`"0"`=月 … `"6"`=日）。`task` を書いたイベントの
ラベルの後ろに `／ 数学 例題` のように付く。曜日別の課題を出さないなら
`weekday_tasks` ごと省略してよい。

判定に出てくる日課タイプが `routines` に無いと、その日は鳴らずにログに残る。

## 使い方（アプリ）

```bash
./build_app.sh      # チャイム.app をビルド
```

Xcode（`swiftc`）が要る。できた `チャイム.app` をダブルクリックするとウインドウが開く。

```
◀ ▶  2026年8月17日（月）                        夏休み A
長期休暇 A
────────────────────────────────────────
✓  04:00   運動・支度・朝食
▶︎  08:15   休憩
   08:45   物理
   21:30   消灯                              消灯
────────────────────────────────────────
次のチャイム  08:15  休憩          [一時停止] [鳴らしてみる] [設定…]
```

- `◀ ▶` で前後の日を見る（「今日」ボタンで戻る）
- `✓` は鳴り終わった時刻、`▶︎` は次に鳴る時刻
- **ウインドウを閉じてもチャイムは鳴り続ける。** 終了は ⌘Q
- メニューバーにも鐘のマークが出て、次のチャイムの時刻が見える

| | |
|---|---|
| ⌘, | 設定 |
| ⌘T | 今すぐ鳴らしてみる |
| ⌘P | 一時停止 / 再開 |
| ⌘R | 予定を読み直す |
| ⌘0 | 予定のウインドウを開く |
| ⌘Q | 終了 |

`設定… > 基本 > Mac のログイン時に自動で起動する` をオンにすると常駐する。

### 設定

| 項目 | 内容 |
|---|---|
| チャイムを鳴らす | オフで全部止まる |
| 音量 | スライダー。「試聴」でその場で確認 |
| 通知 | 鳴らすときに macOS の通知にも内容を出す |
| 予鈴 | 各チャイムの 3分/5分/10分前にも短く鳴らす |

日課ごとの時刻と内容は「日課の編集」から直接書き換えられる（行の追加・削除も可）。
日付ごとに「別の日課にする」「この日は鳴らさない」「この時刻は鳴らさない」も指定できる。
設定は `data/config.json` と `data/routines.json` に保存される。テキストエディタで
直接編集して ⌘R で読み直してもよい。

## 使い方（ターミナル）

アプリを使うなら不要。

```bash
python3 chime.py today      # 今日の日課とチャイム時刻
python3 chime.py week       # この先1週間
python3 chime.py run        # 常駐して鳴らす（Ctrl+C で終了）
python3 chime.py test       # 音の確認
```

`python3 chime.py run` と `チャイム.app` は**同時に使わない**（二重に鳴る）。

## 音

`sounds/` が空のとき、`chime.py` がウェストミンスターの鐘を自分で合成して置く。
そのままで鳴るので、音源を用意する必要はない。

| ファイル | 中身 | 長さ |
|---|---|---|
| `chime.wav` | 通常のチャイム | 14.4秒 |
| `chime_pre.wav` | 予鈴（前半のみ） | 5.6秒 |
| `chime_night.wav` | 消灯用 | 14.4秒 |

旋律はウェストミンスターの鐘（ヘ長調）。

```
キーン  コーン  カーン  コーン        キーン  コーン  カーン  コーン
ファ    ラ      ソ      ド            ド      ソ      ラ      ファ
353Hz  445Hz   397Hz   265Hz        265Hz   397Hz   445Hz   353Hz
```

### 好きな音に入れ替える

mp3 / m4a / wav などをそのまま指定できる。

```bash
python3 tools/set_sound.py chime ~/Desktop/新しい音.mp3
python3 tools/set_sound.py night ~/Desktop/消灯用.mp3
python3 tools/set_sound.py pre   ~/Desktop/新しい音.mp3 --end 5.7
```

wav変換 → 指定範囲の切り出し → 前後の無音落とし → 音量そろえ → 終わりをフェードアウト、
までやって `sounds/` に置く。`--start` `--end` で範囲、`--peak` で音量、`--fade` で
終わりを消す長さを変えられる。

## 仕組みの補足

- スリープ中は鳴らない。スリープしていた間に過ぎたチャイムは、起きたときにまとめて
  鳴らしたりしない（2分以上過ぎたものは黙って飛ばす）
- アプリは予定の計算を `chime.py` に任せている。ターミナルの表示とアプリで予定が
  食い違わないようにするため
