# チャイム

決めた予定どおりに、学校のチャイム（ウェストミンスターの鐘＝キーンコーンカーンコーン）
を鳴らすだけの macOS アプリ。

その日が「平日」なのか「夏休み」なのか「考査日」なのかを判定して、その日課の
区切り時刻にチャイムを鳴らす。Dock に入る普通のアプリで、ウインドウで今日の予定を
見ながら使う。

**設定はすべてアプリの中で完結する。** 予定を書くのに JSON をさわる必要はない。

macOS の標準機能だけで動く（追加インストールは不要）。Python 3 は macOS に最初から
入っているものでよい。

---

## はじめかた

```bash
git clone https://github.com/kloysova/bell.git
cd bell
./build_app.sh
```

できた `チャイム.app` をダブルクリックすると、最初に設定画面が出る。

```
                          🔔
                    チャイムへようこそ
          決めた時刻に学校のチャイムを鳴らします。
          まず、いつからいつまで使うかを決めます。

          使う期間
          始まり                        2026/08/18
          終わり                        2027/03/31

          平日・土曜・日曜・長期休暇・考査日・祝日などの日課を、
          よくある時間割で用意します。時刻も内容も、あとから
          設定画面で自由に変えられます。

                      [ はじめる ]
```

使う期間を決めて「はじめる」を押すと、9種類の日課がひととおり用意されて、
そのまま動きはじめる。あとは設定画面で自分の生活に合わせて直していく。

ビルドには Xcode（`swiftc`）が要る。

## 使い方

```
◀ ▶  2026年8月18日（火）                        夏休み A
長期休暇 A
────────────────────────────────────────
✓  07:00   起床・朝食
▶︎  08:30   午前の勉強
   12:00   昼食・休憩
   22:30   消灯                              消灯
────────────────────────────────────────
次のチャイム  08:30  午前の勉強      [一時停止] [鳴らしてみる] [設定…]
あと 1時間13分
```

- `◀ ▶` で前後の日を見る（「今日」ボタンで戻る）
- `✓` は鳴り終わった時刻、`▶︎` は次に鳴る時刻
- **ウインドウを閉じてもチャイムは鳴り続ける。** 終了は ⌘Q
- メニューバーにも鐘のマークが出て、次のチャイムの時刻が見える

| | |
|---|---|
| ⌘, | 設定 |
| ⌘T | 今すぐ鳴らしてみる |
| ⌘P | 一時停止 / 再開 |
| ⌘R | 予定を読み直す |
| ⌘0 | 予定のウインドウを開く |
| ⌘Q | 終了 |

## 設定（⌘,）

### 基本

| 項目 | 内容 |
|---|---|
| チャイムを鳴らす | オフで全部止まる |
| 音量 | スライダー。「試聴」でその場で確認 |
| 通知 | 鳴らすときに macOS の通知にも内容を出す |
| 予鈴 | 各チャイムの 3分/5分/10分前にも短く鳴らす |
| ログイン時に自動で起動 | オンにすると常駐する |

### カレンダー

**どの日にどの日課をあてるかを、月のカレンダーで決める。**

```
使う期間  2026/04/06 〜 2027/03/20  [変更]

◀  2026年8月  ▶  [今月]        クリックで選ぶ／⇧クリックで範囲／⌘クリックで追加
   日      月      火      水      木      金      土
   2       3 •     4 •     5 •     6 •     7 •     8
  日曜   長期休暇A 長期休暇B 長期休暇A 長期休暇B 長期休暇休 学校土曜
────────────────────────────────────────────────
4日を選択中 — わりあてる日課を選ぶ
[•学校のある平日] [•学校のある土曜] [•日曜] [•長期休暇 A] … [曜日どおりに戻す]
```

- 日課ごとに色がついていて、ひと目でその月の構成が分かる
- クリックで1日、⇧クリックで範囲、⌘クリックで飛び飛びに選べる。
  夏休みのAB交互のような並びも、まとめてわりあてられる
- **わりあてた日には点（•）が付く。** 何もわりあてていない日は曜日どおり
  （月〜金＝学校平日 / 土＝学校土曜 / 日＝通常日曜）になるので、
  ふつうの学校生活なら何もしなくてよい
- 「使う期間」の外の日は鳴らない

### 日課の編集

日課ごとに、**チャイムを鳴らす時刻と内容を直接書き換えられる**。

日課を選ぶ → 表の時刻や内容を打ち替える → 「保存」。行の追加・削除もできる。
音は「通常」「消灯」「予鈴音」から選ぶ。

### そのほか

- **この日は別の日課にする** — 1日だけ例外にする（まとめてやるなら「カレンダー」）
- **この日は鳴らさない** — 旅行の日など
- **この時刻は鳴らさない** — すべての日で、その時刻だけ黙らせる

設定は `data/` に保存される。テキストエディタで直接編集して ⌘R で読み直してもよい。

## 音

`sounds/` が空のとき、`chime.py` がウェストミンスターの鐘を自分で合成して置く。
そのままで鳴るので、音源を用意する必要はない。

| ファイル | 中身 | 長さ |
|---|---|---|
| `chime.wav` | 通常のチャイム | 14.4秒 |
| `chime_pre.wav` | 予鈴（前半のみ） | 5.6秒 |
| `chime_night.wav` | 消灯用 | 14.4秒 |

旋律はウェストミンスターの鐘（ヘ長調）。

```
キーン  コーン  カーン  コーン        キーン  コーン  カーン  コーン
ファ    ラ      ソ      ド            ド      ソ      ラ      ファ
353Hz  445Hz   397Hz   265Hz        265Hz   397Hz   445Hz   353Hz
```

### 好きな音に入れ替える

mp3 / m4a / wav などをそのまま指定できる。

```bash
python3 tools/set_sound.py chime ~/Desktop/新しい音.mp3
python3 tools/set_sound.py night ~/Desktop/消灯用.mp3
python3 tools/set_sound.py pre   ~/Desktop/新しい音.mp3 --end 5.7
```

wav変換 → 指定範囲の切り出し → 前後の無音落とし → 音量そろえ → 終わりをフェードアウト、
までやって `sounds/` に置く。`--start` `--end` で範囲、`--peak` で音量、`--fade` で
終わりを消す長さを変えられる。

## ターミナルから使う場合（任意）

アプリを使うなら不要。

```bash
python3 chime.py init --start 2026-04-06 --end 2027-03-20   # data/ を作る
python3 chime.py today      # 今日の日課とチャイム時刻
python3 chime.py week       # この先1週間
python3 chime.py run        # 常駐して鳴らす（Ctrl+C で終了）
python3 chime.py test       # 音の確認
```

`python3 chime.py run` と `チャイム.app` は**同時に使わない**（二重に鳴る）。

## データの中身

アプリだけで使うなら読まなくてよい。直接編集したい人向け。

`data/` に3つ。`config.json` はアプリが書き換える。

### data/calendar.json

```json
{
 "study_period": { "start": "2026-04-06", "end": "2027-03-20" },
 "types": {
  "2026-08-03": "長期休暇A",
  "2026-08-04": "長期休暇B"
 },
 "days": {
  "2026-07-03": "1学期期末考査",
  "2026-07-20": "海の日"
 }
}
```

- `types` … 日付に日課タイプを直接わりあてる（アプリの「カレンダー」が書くのはここ）
- `days` … 月間カレンダーのマス目に書く文字列。書いておくと下の表の規則で
  日課タイプが決まる。手書きの予定表を取り込むとき用で、ふつうは空でよい

その日の日課タイプは次の順で決まる。

| # | 条件 | 日課タイプ |
|---|---|---|
| 1 | `config.json` の `date_overrides` に指定がある | 指定したもの |
| 2 | `study_period` の外 | 鳴らさない |
| 3 | `types` にわりあてがある | そのタイプ |
| 4 | `days` が `夏休み` `冬休み` `春休み` + `A`/`B`/`休` | `長期休暇A` / `長期休暇B` / `長期休暇休` |
| 5 | `days` が `考査` を含む | `定期考査日` |
| 6 | `days` が `休養調整日` | `休養調整日` |
| 7 | `days` にその他の記載（`海の日` など） | `祝日` |
| 8 | 上のどれでもない | 曜日で `学校平日`(月-金) / `学校土曜` / `通常日曜` |

### data/routines.json

```json
{
 "weekday_tasks": {
  "0": { "朝": "数学 例題", "放課後": "数学 問題集" }
 },
 "routines": {
  "学校平日": {
   "title": "学校のある平日",
   "events": [
    { "time": "06:30", "label": "起床・朝食", "sound": "chime" },
    { "time": "07:00", "label": "朝自習",     "sound": "chime", "task": "朝" },
    { "time": "22:30", "label": "消灯",       "sound": "night" }
   ]
  }
 }
}
```

| キー | 内容 |
|---|---|
| `time` | `HH:MM`。この時刻に鳴る |
| `label` | ウインドウと通知に出る文字列 |
| `sound` | `chime`（通常）/ `night`（消灯用）。省略すると `chime` |
| `task` | `weekday_tasks` から曜日別の課題名を引いてラベルに足す（任意） |

`weekday_tasks` はキーが曜日（`"0"`=月 … `"6"`=日）。`task` を書いたイベントの
ラベルの後ろに `／ 数学 例題` のように付く。使わないなら省略してよい。

日課タイプは9種類（`学校平日` `学校土曜` `通常日曜` `長期休暇A` `長期休暇B`
`長期休暇休` `定期考査日` `休養調整日` `祝日`）。

## 仕組みの補足

- スリープ中は鳴らない。スリープしていた間に過ぎたチャイムは、起きたときにまとめて
  鳴らしたりしない（2分以上過ぎたものは黙って飛ばす）
- アプリは予定の計算を `chime.py` に任せている。ターミナルの表示とアプリで予定が
  食い違わないようにするため
- `./build_app.sh --test` で、画面を出さずに動作確認だけできる
